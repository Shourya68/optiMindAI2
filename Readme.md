
# OptiMind AI – DAA Workbench

## Project Overview
OptiMind AI is an interactive web-based algorithm visualization platform developed using HTML, CSS and JavaScript.

It demonstrates two fundamental concepts of Design and Analysis of Algorithms.

## Algorithms Implemented

### 1. QuickSort
- Algorithm paradigm: Divide and Conquer
- Uses Lomuto Partitioning
- Displays animated array sorting
- Tracks the number of comparisons
- Average Time Complexity: O(n log n)
- Worst Time Complexity: O(n²)

### 2. Greedy Activity Selection
- Algorithm paradigm: Greedy Method
- Sorts activities by finishing time
- Selects maximum compatible activities
- Allows users to add and remove tasks
- Time Complexity: O(n log n)

## Technology Stack
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the Optimind-AI folder.
3. Open index.html in Google Chrome or another browser.
4. Start exploring the algorithms.

## Project Purpose
To make algorithmic concepts easier to understand through interactive visualization and practical examples.
